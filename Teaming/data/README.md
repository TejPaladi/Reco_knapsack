This folder contains the data generated by the ULTRA-Matching system.

### Data
- [V0_Recommendation (original).csv](https://github.com/ai4society/Ultra-Matching/blob/likitha/likitha/data/V0_Recommendation%20(original).csv) - CSV output file containing researcher names, their interests, proposals recommended to them, etc. This is the output that came from Version0 of code/data. (Published in ICDM Workshop 2022)
- [V0_Recommendation_output.csv](https://github.com/ai4society/Ultra-Matching/blob/likitha/likitha/data/V0_Recommendation_output.csv) - same as above but some columns have been dropped for better viewability
- [V0_proposal_links_title_synopsis.csv](https://github.com/ai4society/Ultra-Matching/tree/likitha/likitha/data#:~:text=V0_proposal_links_title_synopsis.csv) - Original set of RFPs and titles/synopsis extracted from their URLs.
- [V0_M0_common_interests.csv](https://github.com/ai4society/Ultra-Matching/blob/likitha/likitha/data/V0_M0_common_interests.csv) - apply M0 on the original V0 data. Then, check why a faculty member has been recommended a certain proposal in the first place. (As in, check the common interests between the faculty member's skillset vs. the RFP's required skills.)
- [V0_M1_Dump.csv](https://github.com/ai4society/Ultra-Matching/blob/likitha/likitha/data/V0_M1_Dump.csv) - results of M1 (using the mapper method) on V0 data
- [V1_files](https://github.com/ai4society/Ultra-Matching/tree/likitha/likitha/data/V1_files) - data regarding updated faculty lists and RFP calls (both from Nov 2022)
